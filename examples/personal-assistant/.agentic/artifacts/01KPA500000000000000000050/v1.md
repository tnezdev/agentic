# Example Workspace Context

## Project

This fictional workspace explores how a personal assistant can reconstruct context from durable primitives before acting.

## Local Rules

- Keep all fixture data fictional and public-safe.
- Do not add live integrations in the first slice.
- Preserve the Agentic/harness boundary: Agentic prepares context and state; the harness executes model calls and tools.
- Prefer one clear session-start workflow over a broad assistant platform.

## Success Criteria

- A fresh reader can run the example and understand the assistant startup loop.
- The ready task selects the assistant persona, session-brief skill, and session-start workflow without ambiguity.
- The assistant produces a durable `session-brief` artifact using only fixture context.
- The next-step recommendation is small enough to act on immediately.
